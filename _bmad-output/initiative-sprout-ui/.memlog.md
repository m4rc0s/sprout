- (requirement) R1 (plan: Parte B, o momento uau) One command, sprout ui, opens the UI on this machine; a visitor without the run's token, or from a foreign origin or host, is refused. Shown by 401 without token and 403 on a foreign Origin.
- (requirement) R2 (plan: Parte B, o momento uau) The user pastes markdown of any length, picks a destination and gets a new project there with no flags. Shown by the destination holding a git repository with the pasted text saved as the project's spec and an initial commit.
- (requirement) R3 (plan: Fatia 1) Destination and name are suggested from the text's title and stay editable; an empty, relative, parent-traversing or already-occupied destination is explained in the screen's words before any file is created. Shown by no directory created for each refused destination.
- (requirement) R4 (plan: Fatia 1) While planting, each step appears as it happens, in order; a failure states what went wrong and how to fix it. Shown by the log matching what sprout plant prints, and the occupied-destination case ending with a message that names the destination.
- (requirement) R5 (plan: o momento uau, passo 3) After planting with an agent enabled, an agent starts on its own in plan mode on the project's spec; the user can choose auto, claude, agy, codex, or none (repository only, no agent). Shown by the agent appearing in herdr agent list with the project's directory as its cwd, and by none leaving no agent.
- (requirement) R6 (plan: Fatia 3) The agent's terminal is shown on the same screen as the plant, without leaving it, and follows what the agent prints within about one second. Shown by a line printed by the agent appearing in the embedded terminal within about one second.
- (requirement) R7 (plan: Fatia 3) The user types in the embedded terminal and the agent receives it, including Enter, arrow keys, Tab, Esc and Ctrl-C. Shown by an answer typed in the UI being received by the agent and the agent replying.
- (requirement) R8 (plan: Fatia 1 e 3, limites) When Herdr is missing, when the agent is not found in time, or when its pane closes, the screen says what happened and how to continue instead of failing silently; the created project is never hidden. Shown by the three situations each producing a distinct message.
- (requirement) R9 (plan: o momento uau) From clicking Plant to seeing the agent's terminal with output takes about 15 seconds on the user's machine with Herdr running. Shown by a measured run.
- (requirement) R10 (plan: Etapas BMad, UX) The screen is fully operable by keyboard and its progress is announced to assistive technology; motion respects reduced-motion. Shown by completing plant-and-watch without a mouse and by no animation under reduced-motion.
- (constraint) C1 (plan: Arquitetura de alto nivel) Every change to Sprout state (create project, start agent) goes through the sprout CLI; the UI server does not reimplement it. It reads from herdr, git and .sprout files.
- (constraint) C2 (plan: Seguranca) Local only: bound to 127.0.0.1, per-run token, Origin and Host validated, user text never interpolated into a command line (argv without shell), request payloads validated against a schema, destination paths validated.
- (constraint) C3 (user decision, Sally session) Visual identity enters only through the token file, defined by DESIGN.md: OKLCH tokens, no hardcoded colors in components, lucide-react icons only, no emoji, WCAG AA, prefers-reduced-motion.
- (constraint) C4 (plan: Regras mantidas do catalogo) Performance: independent I/O in parallel, no barrel files, heavy modules (terminal) loaded on demand, state derived at render, no effect-based syncing.
- (constraint) C5 (plan: Regras mantidas do catalogo; ft_bpo_shell agent configs) Git: branch only, never main, Conventional Commits in English, tests and typecheck green before each commit, merge only with the user's explicit approval.
- (constraint) C6 (decision: shell first) The screen talks to Sprout only through the SproutApi interface; a mock implementation (scenarios ok, erro, sem-herdr via ?cenario=) and the real one are interchangeable, and the prototype lives inside the product's structure, not beside it.
- (constraint) C7 (plan: Decisoes do usuario) Stack fixed to the first proposal and only ratified by the architecture spine: Bun, TypeScript, React 19, React Router 7 SPA, Vite, Tailwind, zod, bun test; terminal is xterm in mirror-plus-keyboard form (herdr pane read --ansi, send-text, send-keys).
- (decision) Out of the MVP (phase 2), dated 2026-11-08: recent projects, session list and management (resume, new, stop, remove), handoff and task tabs, keyboard shortcuts, autopilot panel, agent telemetry, config editing, PTY terminal, remote or multi-user access.
- (assumption) sprout plant runs correctly when started by a server process with no TTY and stdin closed. To be proved first by the tracer slice.
- (assumption) The agent started by plant is found by matching herdr agent list cwd (or foreground_cwd) to the destination.
- (assumption) The 15 second target is measured on the user's machine with Herdr already running and a local repository destination.
- (question) Visual identity: is the HUD / sci-fi FUI style the identity or only a reference; dark only; green as the sprout brand color; treatment of the long markdown field; ticker; amount of motion. Waits on: ux-plant-and-watch (Sally).
- (question) Does _bmad/ go into git or into .gitignore? Waits on: the user.
- (direction) Source: docs/plans/sprout-ui-reference.md (committed plan), plus the decisions the user made in the session; the ux-plant-and-watch run is an adopted companion still in progress.
